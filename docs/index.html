Learn cybersecurity by doing. Each lesson pairs a short, plain explanation with a small exercise you work through yourself, and ends with the defensive takeaway. Pick one to begin.

Everything here is sandboxed and runs entirely in your browser. Nothing you type is uploaded, and there is no real attack tooling or live target anywhere in it. The point is to understand how something works so you can defend against it.

Manara means lighthouse, a guiding light. Built as an open learning tool. Source on GitHub.
